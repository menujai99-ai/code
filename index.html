    Home-screen widget

    iPhone widgets come from the free Scriptable app. The widget loads its code and your countdowns from GitHub, so edits there show up on your home screen by themselves.

    1. ✓ Widget sync is on. Every countdown you add, edit or delete here is sent to GitHub automatically. Turn on so every countdown you add here shows up on the widget automatically.
    2. Install Scriptable from the App Store.
    3. then in Scriptable tap +, paste, and name it Dots. (One time only, for all countdowns.)
    4. On your home screen, long-press → + → Scriptable, and pick a small, medium or large widget.
    5. Long-press the widget → Edit Widget → Script: Dots. For Parameter, enter the name:

    Widget sync

    Dots saves your countdowns to widget/countdowns.json in your GitHub repo whenever you add, edit or delete one, and the widget reads them from there.

    1. On GitHub, create a fine-grained token: Repository access → Only select repositories → your repo; Permissions → Contents → Read and write. Copy the token.
    2. Paste it below and tap Save & sync.
    The token is stored only in this app on this phone.
