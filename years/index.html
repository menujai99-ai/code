    Home-screen widget

    iPhone widgets come from the free Scriptable app. The widget loads its code and your items from GitHub, so changes you make here show up on your home screen by themselves.

    1. ✓ Widget sync is on. Every item you add, edit or delete here is sent to GitHub automatically. Turn on so every item you add here shows up on the widget automatically.
    2. Install Scriptable from the App Store.
    3. then in Scriptable tap +, paste, and name it Years. (One time only, for all items.)
    4. On your home screen, long-press → + → Scriptable, and pick a small, medium or large widget.
    5. Long-press the widget → Edit Widget → Script: Years, When Interacting: Run Script. For Parameter, enter the name:

    Widget sync

    Years saves your items to years/widget/years.json in your GitHub repo whenever you add, edit or delete one, and the widget reads them from there. If Widget sync is already on in Dots, the same token is used here.

    1. On GitHub, create a fine-grained token: Repository access → Only select repositories → your repo; Permissions → Contents → Read and write. Copy the token.
    2. Paste it below and tap Save & sync.
    The token is stored only in this app on this phone.
